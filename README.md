# 🔍 ماسح أسعار USDT/LYD — بايننس P2P

ماسح لحظي لمسح وتحليل وعرض أسعار بيع وشراء عملة USDT بالدينار الليبي (LYD) من منصة بايننس P2P.

**الميزات:** أسعار حية (أفضل/متوسط/وسيط) • جداول أفضل الإعلانات • رسم بياني • سبريد السوق • 🔔 تنبيهات سعرية (صوت + إشعار) • 🆕 قائمة مستقلة للعروض الجديدة • ❌ قائمة مستقلة للعروض المنتهية • 📅 **سجل يومي تام** (`docs/daily/`) يحفظ دورة حياة كل عرض بالتاريخ ووقت الإعلان ووقت الانتهاء والمدة — عارض بالتاريخ في اللوحة مع ملخص وتصفية وتصدير CSV.

## 🐙 النشر المجاني على GitHub Pages (مستضاف بالكامل — بدون خادم)

نشر دائم ومجاني 100%: لوحة ويب تعمل 24/7 دون أن يشغّل جهازك شيئاً.

**كيف يعمل؟**
- `GitHub Actions` يشغّل الماسح **كل دقيقة فعلياً** (حلقة داخلية لمدة 58 دقيقة كل ساعة — لأن cron في GitHub لا يدعم دقيقة واحدة) ويحدّث `docs/data.json` في المستودع
- `GitHub Pages` يعرض اللوحة من مجلد `docs` للزوار من أي مكان

**الطريقتان:**

```bash

```

ب) يدوياً: اتبع الخطوات المصوّرة في [MANUAL-DEPLOY.md](MANUAL-DEPLOY.md)

الرابط النهائي: `https://USERNAME.github.io/usdt-lyd-scanner/`

> ملاحظات: المستودع **Public** مطلوب لـ Pages المجانية — وهو يجعل Actions مجانياً غير محدود أيضاً (الحساب التفصيلي: [docs/ACTIONS-COST.md](docs/ACTIONS-COST.md)). لتقليل التكرار غيّر `cron` في `.github/workflows/scanner.yml`.

## ⚡ التشغيل المحلي (تحديث لحظي كل 10 ثوانٍ)

### 1️⃣ الواجهة الحية (لوحة تحكم ويب)

```bash
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

- تحديث تلقائي كل 10 ثوانٍ (بث لحظي عبر SSE)
- أفضل أسعار الشراء والبيع + متوسط ووسيط السوق
- جداول بأفضل 10 إعلانات لكل جهة (السعر، المتاح، الحدود، التاجر، نسبة الإتمام)
- رسم بياني لحركة السعر الأوسط
- ووميض أخضر/أحمر عند تغير السعر
- 🔔 **تنبيهات سعرية**: حدد حداً لسعر الشراء (ينبّهك عند تجاوزه) أو سعر البيع (ينبّهك عند نزوله تحته) — التنبيه يأتي بصوت + إشعار متصفح + إشعار داخل اللوحة، وتُحفظ حدودك تلقائياً في المتصفح

لتغيير فاصل التحديث:

```bash
REFRESH_SEC=5 npm start
```

### 2️⃣ سطر الأوامر (مسح واحد)

```bash
npm run scan
```

### 3️⃣ سطر الأوامر (مراقبة مستمرة كل 15 ثانية)

```bash
npm run cli
```

أو بفاصل مخصص:

```bash
node scanner.js --interval=30
```

## كيف يعمل؟

- يجلب الماسح الإعلانات من واجهة بايننس P2P العامة (`p2p.binance.com/bapi/.../adv/search`)
- `tradeType=BUY` → إعلانات شراء USDT بالدينار (أرخص سعر = أفضل لك كمشترٍ)
- `tradeType=SELL` → إعلانات بيع USDT مقابل الدينار (أعلى سعر = أفضل لك كبائع)
- يحسب: أفضل سعر، متوسط، وسيط، إجمالي المعروض، والسبريد بين الجهتين

> ملاحظة: السوق الليبي قد يظهر أحياناً "سبريد مقلوب" (أفضل بيع أقل من أفضل شراء) بسبب فجوة السيولة بين المعلنين — يعرضه الماسح بقيمة سالبة كما هو.

## 🚀 التشغيل التلقائي (خادم + نفق + رابط فوري)

أسرع طريقة: سكريبت واحد يشغّل كل شيء ويعرض الرابط العام مباشرة:

```bash
bash start.sh
```

على ويندوز: انقر مزدوجاً على `start.bat`

يقوم السكريبت تلقائياً بـ:
1. تشغيل الخادم المحلي (أو استخدامه إن كان يعمل)
2. فتح نفق عام عبر serveo
3. عرض الرابط العام جاهزاً للمشاركة + التحقق من أنه يعمل
4. عند الضغط Ctrl+C يُغلق الخادم والنفق معاً

## 🌐 النشر اليدوي على الإنترنت (رابط عام)

لمشاركة الماسح مع أي شخص عبر الإنترنت، أنشئ نفقًا عامًا باستخدام ssh:

```bash
ssh -o StrictHostKeyChecking=no -R 80:localhost:3000 serveo.net
```

سيظهر لك رابط مثل:
`https://xxxx-xxxx.serveousercontent.com`

ملاحظات مهمة:
- الرابط يعمل فقط طالما الخادم والنفق يعملان على جهازك (أغلق الطرفية = يتوقف الرابط)
- عند إعادة التشغيل قد يتغيّر الرابط
- قد تظهر للزوار صفحة تحذير من serveo أولاً، اضغطوا "متابعة" للدخول
- لرابط ثابت ودائم، استخدم خدمة مثل cloudflared أو ngrok

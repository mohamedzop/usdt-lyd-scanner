# 📊 حساب استهلاك GitHub Actions — ماسح كل دقيقة

> ⚠️ **حقيقة تقنية مهمة:** مجدول `cron` في GitHub Actions **لا يضمن التكرار الأقل من 5 دقائق** — حتى لو كتبت `* * * * *` ستتأخر التشغيلات وترتجل (أحياناً 5-30 دقيقة عند الضغط). لذلك صممنا **حلقة داخلية**: سير عمل يبدأ كل ساعة ويمسح فعلياً **كل دقيقة لمدة 58 دقيقة** داخل نفس التشغيل.

## كيف يعمل النظام الحالي

```
كل ساعة: تشغيل واحد من Actions (cron: '7 * * * *')
   └── حلقة داخلية: 58 دورة × (مسح ~3 ثوانٍ + انتظار 55 ثانية)
       └── كل دورة تمسح + ترفع فوراً (كوميت متجدد) لتصل اللوحة كل دقيقة
       └── تُحدّث data.json + history.json + newads.json (كشف الإعلانات الجديدة)
```

**النتيجة:** بيانات تتحدث كل دقيقة فعلاً (وليس كل 5+ كما يفعل cron الأدنى)، مع كوميت واحد في الساعة فقط.

## الأرقام المقاسة فعلياً (من هذا الجهاز)

| البند | القيمة |
|---|---|
| زمن المسح الواحد | **2.2 ثانية** (مقاس: fetch جهتين × صفحتين) |
| زمن التشغيل الواحد على Actions | ~10 ثوانٍ إعداد + 58 دقيقة حلقة ≈ **59 دقيقة** |
| عدد التشغيلات شهرياً | 24 يومياً × 30 = **720 تشغيل** |
| **الدقائق المستهلكة شهرياً** | 720 × 59 ≈ **42,500 دقيقة/شهر** |

## هل يبقى مجانياً؟

| نوع المستودع | الحد المجاني | استهلاكنا | النتيجة |
|---|---|---|---|
| **Public** ✅ (المستخدم للنشر) | **غير محدود** | 42,500 | **مجاني تماماً** ✅ |
| Private ❌ | 2,000 دقيقة | 42,500 | يتجاوز الحد ×21 — مدفوع |

> **الخلاصة:** ما دام المستودع **Public** (وهو مطلوب أصلاً لـ GitHub Pages المجانية) — الاستهلاك **لا يهم إطلاقاً** لأن Actions مجاني غير محدود للمستودعات العامة.

## ضمانات مدمجة في السير

1. **`timeout-minutes: 66`** — سقف صارم للتشغيل، مستحيل يحرق دقائق بلا نهاية
2. **`concurrency: cancel-in-progress`** — التداخل مستحيل، الأحدث يلغي الأقدم
3. **فشل دورة واحدة لا يوقف الحلقة** — `|| echo` يسمح بالمتابعة للدورة التالية
4. **كوميت متجدد (amend)** — سجل git نظيف: 24 كوميت/يوم فقط بدل 1,440
5. **تخطي الحفظ عند عدم التغيير** — لا push فارغ
6. **هامش أمان** — 58 دقيقة حلقة + 2 دقيقة حفظ < ساعة، والتشغيل التالي يبدأ من نقطة نظيفة

## حدود الاستخدام العادل (شروط GitHub)

المجاني غير المحدود للمستودعات العامة مشروط بـ "الاستخدام المعقول لأغراض التطوير والإنتاج القياسية" — ماسح أسعار خفيف (طلبان HTTP كل دقيقة) **داخل الاستخدام المقبول بوضوح**. المحظور: التعدين، بث الفيديو، الاستضافة الكبيرة المستمرة — لا ينطبق أي منها علينا.

## لو أضفت عملات أخرى لاحقاً

العملات الإضافية تُضاف **داخل نفس الحلقة** (حلقة for على العملات داخل كل دورة دقيقة) — التشغيل نفسه يطول ثوانٍ قليلة فقط لأن الدقائق محددة بالحلقة لا بعدد العملات:
